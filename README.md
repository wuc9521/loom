# Logic Learning Language Parser

Frontend of Logic Learning Problems

To run the project.

Install dependencies.

```bash
cargo install
```

Some examples

```bash
# First Order Logic
cargo run -- --input ./exp/fol/1.sl

# Propositional Modal Logic
cargo run -- --input ./exp/pml/1.sl

# Regular Expression
cargo run -- --input ./exp/re/1.sl 
```
