# README

$\textsf{FO}$ is the logic of first order logic with $\textsf{ITE}$

$$
\begin{aligned}
\textbf{Form}&:=\textsf{T}\mid \textsf{F}\mid P(t_1,t_2,\ldots,t_n)\mid t_1=t_2\mid \forall v.\varphi\mid \exists v.\varphi\mid \neg\varphi
\\ 
\textbf{Term}&:=v\mid x\mid f(t_1,t_2,\ldots,t_n)\mid \textsf{ITE}(\varphi, t_1,t_2)
\end{aligned}
$$
